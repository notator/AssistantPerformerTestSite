2. Regions and Interpretations should be properly documented:
Interpretations (which are temporal information) are stored in parallel <midiChord> or <midiRest> elements inside <midiChords> or
<midiRests> elements inside SVG <g class "chord"> or <g class "rest"> elements. Each <g class "chord"> or <g class "rest"> element also
contains a single <g class="graphics"> element that defines the symbol's appearance.
<g class="chord">
    <score:midiChords>
        <midiChord> <!-- interpretation 1 -->
            ...
        </midiChord>
        <midiChord> <!-- interpretation 2 -->
            ...
        </midiChord>
        ... <!-- more <midiChord> elements (interpretations) ad lib. -->
    </score:midiChords>
    <g class="graphics">
        ...
    </g>
</g>
And similarly for <g class="rest">. (Different rest interpretations simply have different durations.)
Interaction between the InterpretationSelect control, the startMarker and endMarker:
All scores contain 1 or more Regions. 
If a score contains more than one Region, then each Region determines the interpretation that it will play. The InterpretationSelect control
is therefore populated by all the _Regions_ in the score: "region A", "region B", etc.
If a score contains only one Region, then the user is given control of which interpretation is to be played. The InterpretationSelect control
will then be populated by all the _Interpretations_ in the score: "interpretation 1", "interpretation 2", etc.
If there is only one Region and one Interpretation, the control displays "interpretation 1" but is disabled (greyed out).
Using the InterpretationSelect control to select a Region sends the startMarker to the beginning of that Region, and the endMarker to the end
of the score (otherwise the startMarker could end up later than the endMarker).
Using the InterpretationSelect control to select an Interpretation selects the interpretation without affecting the (graphical) startMarker and
endMarker positions.
If the setStartMarker tool is used to position the startMarker somewhere in a region, the InterpretationsSelect will be updated to that Region. 
I'm using the following three test scores
a) Tombeau 1 (multiple regions, but only one interpretation in the score)
b) Study 1 (1 region with 2 interpretations)
c) Pianola Music (multiple regions with multiple interpretation levels -- Region B uses Interpretation 2)

Comment: Also see the blue-boxed note apropos the remarks at the start of Part 4 of Retrospective 2024 (Also, see my 9th July notebook entry.):
The decision to implement multiple interpretations of a score has to do with the way performance practice traditions develop (through the
use of different recordings of the same piece). There is never a single, perfect performance of a score that is intended to be interpreted by
humans.
Performances using the Assistant Performer´s conducting options are problematic: its impossible to know _exactly_ when the next event will
happen when the mouse is moved. One can´t see into the future. This is why I wrote the ResidentSynthHost´s ability to trigger events _exactly_
when the performer presses a key on the keyboard, and to record the result.  When recording in the ResidentSynthHost, the performer decides
_which_ key to press, and _when_, depending on his/her memory (of how to read, and all other previous experience). In other words, the decision
of when to press the key depends on who the performer _is_ -- i.e. what his/her _memories_ are, who he/she has been trained to be. 
Its a performer´s unique _mind_ (memory, spirit) that communicates in time. We don´t know how or where the performer´s memories are stored,
but that´s actually irrelevant here. Its also irrelevant to ask whether "free-will" is involved: All we need to know is that it seems to be
working (much in the same way that all that´s relevant about space, time and information is how we _experience_ them. What they, and "free will"
"really" are (maybe when _mathematically_ defined) isn´t relevant to how we experience them. Experiencing someone's unique performance of a
score is to experience "what it is like to be" someone else. Its comforting to know that we are not alone.
